# Buyer Demo Walkthrough

The maintained buyer-demo script now lives at `docs/client-readiness/buyer-demo.md`.

Use **Admin → Demo Readiness** before every prospect meeting. Prepare a disposable reference tenant, clear all required checks, open the five demo tabs, and test one printed QR code over cellular data.

The old 20-minute product tour was retired because it encouraged feature wandering and included integration claims that were broader than the verified product. The current story is 15 minutes: understand the day, communicate one confirmed change, show the family QR experience, demonstrate accountable operations, optionally show sponsor proof, and make the one-date pilot ask.
