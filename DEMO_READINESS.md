# Demo Readiness

Use `/admin/demo` as the system of record for reference-demo readiness.

The maintained buyer script and implementation materials are under `docs/client-readiness/`. The integration matrix there controls what may be represented as live, implemented but unverified, framework/demo-only, or future.

Before a meeting:

1. Run `npm run verify:client-readiness`.
2. Open Admin → Demo Readiness.
3. Prepare a disposable reference demo tenant.
4. Clear every required check.
5. Test a public field QR code over cellular data.
6. Follow `docs/client-readiness/buyer-demo.md` and stop after the pilot ask.
